Tại studio, chúng tôi không chỉ làm game, chúng tôi tạo ra những thế giới sống động. Bạn sẽ tham gia vào đội ngũ nòng cốt phát triển một tựa game nhập vai phiêu lưu hành động 3D (Action RPG) đa nền tảng (PC/Console &amp; Mobile) với đồ họa phong cách Stylized.

## 🕹️ Trọng trách chuyên môn

- Lập trình logic Gameplay, cơ chế điều khiển nhân vật, hệ thống chiến đấu (Combat system), AI của Boss và quái vật bằng C# (Unity) hoặc C++ / Blueprints (Unreal Engine).
- Tối ưu hóa hiệu năng render (Draw calls, Batches, Memory footprint, Frame rate lock 60fps trên mobile).
- Làm việc chặt chẽ với Technical Artist để tích hợp hiệu ứng hình ảnh (VFX), đổ bóng (Shaders), Animation trees và âm thanh vào bối cảnh trò chơi.
- Tích hợp các SDK dịch vụ: Multiplayer Networking (Photon / Mirror), Lưu trữ đám mây (Cloud Save), In-App Purchase và Leaderboard.
- Xây dựng và duy trì các công cụ nội bộ (Custom Editor Tools) giúp Game Designer dễ dàng cân bằng chỉ số trang bị mà không cần sửa code.

- Tối thiểu 2 năm kinh nghiệm lập trình game thương mại trên engine Unity hoặc Unreal Engine.
- Nắm vững kiến thức toán học trong không gian 3 chiều: Vector, Quaternion, Matrix transformations, Raycasting, Collision detection.
- Viết code sạch, hiểu sâu về Object Pooling, State Pattern, Command Pattern và Dependency Injection trong kiến trúc game.
