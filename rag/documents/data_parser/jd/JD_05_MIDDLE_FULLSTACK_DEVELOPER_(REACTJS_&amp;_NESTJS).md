## [JD 05] MIDDLE FULLSTACK DEVELOPER (REACTJS &amp; NESTJS)

- Loại hợp đồng: Chính thức, toàn thời gian
- Nơi làm việc: Quận Bình Thạnh, TP. Hồ Chí Minh
- Mức đãi ngộ: 30.000.000 - 45.000.000 VNĐ Net

## 💼 Key Responsibilities

- Đảm nhận phát triển end-to-end các tính năng mới từ giao diện người dùng (Front-end) tới logic nghiệp vụ máy chủ (Back-end) cho nền tảng SaaS B2B.
- Xây dựng giao diện responsive, tối ưu Web Vitals bằng ReactJS, Next.js, Tailwind CSS và Redux Toolkit/Zustand.
- Thiết kế kiến trúc Back-end sử dụng Node.js (NestJS framework), áp dụng Clean Architecture hoặc Hexagonal Architecture.
- Thiết kế cơ sở dữ liệu quan hệ (PostgreSQL) và bộ nhớ tạm (Redis caching), tối ưu hóa tốc độ load trang dưới 1.5s.
- Tích hợp các dịch vụ bên thứ ba: Stripe, SendGrid, Twilio, AWS S3.
- Đóng góp ý kiến cải tiến UI/UX cùng bộ phận Product &amp; UI/UX Designer.

## 📌 Yêu cầu chuyên môn

1. Có từ 2.5 đến 4 năm kinh nghiệm lập trình Fullstack với JavaScript/TypeScript ecosystem.
2. Frontend: Thành thạo ReactJS/Next.js, nắm chắc kỹ thuật Server-Side Rendering (SSR), Static Site Generation (SSG).
3. Backend: Nắm vững NestJS (hoặc Express.js nâng cao), hiểu sâu về Dependency Injection, Middleware, Interceptors, Guard.
4. Database: Kinh nghiệm làm việc với TypeORM hoặc Prisma; biết cách phân tích slow query và đánh index hợp lý.
5. Tools: Quen thuộc với Git flow, Docker Compose, CI/CD cơ bản.
6. Tinh thần trách nhiệm cao (Ownership), chủ động đề xuất giải pháp thay vì chỉ nhận task thụ động.
