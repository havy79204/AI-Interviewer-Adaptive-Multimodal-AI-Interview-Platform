## [JD 10] INTERN BACKEND DEVELOPER (JAVA / SPRING BOOT)

- Chương trình: Talent Incubation Program (Backend Track)
- Thời lượng: 3 - 6 tháng
- Địa điểm làm việc: Khu Công nghệ cao Hòa Lạc, Thạch Thất, Hà Nội (Có xe bus đưa đón 2 chiều từ nội thành)

## 🎯 Bạn sẽ được trải nghiệm những gì?

- Tham gia trực tiếp vào các dự án phần mềm doanh nghiệp quy mô lớn (Enterprise Systems) của khách hàng khối Tài chính - Ngân hàng.
- Được đào tạo bài bản về kiến trúc Microservices, Clean Code, Design Patterns dưới sự hướng dẫn của Senior Java Engineers.
- Tham gia viết các API CRUD cơ bản, xử lý nghiệp vụ với framework Java Spring Boot.
- Thực hành viết unit test bằng JUnit 5 và Mockito, làm quen với SonarQube để rà soát lỗi bảo mật và code smell.
- Làm quen với quy trình phát triển phần mềm chuẩn CMMI Level 5 và Agile/Scrum.

## 🎁 Chính sách hỗ trợ &amp; Phát triển

- 💵 Trợ cấp thực tập: 6.000.000 - 9.000.000 VNĐ/tháng (được xét duyệt dựa trên bài test thuật toán &amp; kiến thức Java).
- 🚌 Xe đưa đón miễn phí các tuyến cố định từ các quận nội thành Hà Nội lên campus Hòa Lạc.
- ☕ Miễn phí cơm trưa tại canteen công ty với thực đơn phong phú, đa dạng.
- 📜 Cấp chứng chỉ hoàn thành khóa thực tập và hỗ trợ tối đa việc ký nhận xét thực tập tốt nghiệp.
- 🎯 Cơ hội vàng: Tỉ lệ ký hợp đồng lao động chính thức (Junior Developer) đạt &gt;85% đối với các bạn hoàn thành tốt giai đoạn thực tập.
