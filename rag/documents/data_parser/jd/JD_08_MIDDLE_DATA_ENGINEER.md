## [JD 08] MIDDLE DATA ENGINEER

- Team: Big Data &amp; Analytics Platform
- Vị trí làm việc: Cầu Giấy, Hà Nội
- Mức lương tham chiếu: $1,400 - $2,200 Gross

## 📊 Nhiệm vụ trọng tâm

- Thiết kế, xây dựng và vận hành các pipeline dữ liệu quy mô lớn (Batch &amp; Streaming Data Pipelines) từ nhiều nguồn khác nhau (RDBMS, Event logs, Third-party APIs).
- Xây dựng kiến trúc Data Warehouse và Data Lake tuân theo mô hình Medallion (Bronze/Silver/Gold layers) trên nền tảng Cloud (AWS/GCP).
- Phát triển các luồng xử lý dữ liệu tự động hóa qua Apache Airflow / Dagster.
- Tối ưu hóa chi phí lưu trữ và hiệu năng truy vấn của hệ thống dữ liệu lớn bằng cách tối ưu partition, file format (Parquet, Iceberg/Delta Lake).
- Phối hợp với Data Analyst và Business Intelligence Team cung cấp các bảng dữ liệu chuẩn hóa phục vụ báo cáo quản trị.
- Triển khai Data Governance: phân quyền dữ liệu, giám sát Data Lineage và bảo mật dữ liệu nhạy cảm (PII masking).

## 🛠️ Kỹ năng &amp; Kinh nghiệm yêu cầu

- Tối thiểu 2.5 năm kinh nghiệm thực chiến ở vị trí Data Engineer.
- Thành thạo ngôn ngữ lập trình Python hoặc Scala/Java.
- Có kinh nghiệm làm việc thực tế với các công nghệ Big Data: Apache Spark (PySpark), Apache Kafka hoặc Kafka Streams.
- Trình độ SQL xuất sắc; am hiểu chuyên sâu về thiết kế Data Modeling (Star Schema, Snowflake Schema).
- Đã từng triển khai trên một trong các nền tảng Cloud DWH: Snowflake, BigQuery, AWS Redshift hoặc Databricks.
- Có tư duy cẩn trọng về Data Quality và tính toàn vẹn của dữ liệu (Data Integrity).
