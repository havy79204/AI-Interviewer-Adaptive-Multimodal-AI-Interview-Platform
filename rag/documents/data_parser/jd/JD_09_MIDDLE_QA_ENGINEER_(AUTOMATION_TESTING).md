## [JD 09] MIDDLE QA ENGINEER (AUTOMATION TESTING)

- Bộ phận: Quality Engineering
- Địa điểm: Quận 7, TP. Hồ Chí Minh
- Mức lương: 25.000.000 - 38.000.000 VNĐ/tháng

## 🧪 Trách nhiệm chuyên môn

- Chịu trách nhiệm chính về chất lượng của sản phẩm phần mềm trước khi phát hành đến tay người dùng.
- Xây dựng, mở rộng và duy trì Automation Test Framework cho cả Web (Playwright/Cypress) và API (RestAssured/Postman/Newman).
- Tích hợp bộ kiểm thử tự động vào hệ thống CI/CD (GitHub Actions / Jenkins) để chạy tự động mỗi khi có pull request mới.
- Phân tích kết quả test tự động, điều tra nguyên nhân gốc rễ (Root Cause) của các case test fail và tạo bug report chi tiết.
- Thực hiện Performance Testing, Load Testing định kỳ bằng k6 hoặc JMeter cho các đợt cao điểm chiến dịch (Mega Sale).
- Tham gia cải tiến quy trình QA trong mô hình Agile/Scrum, hướng dẫn các bạn Junior trong team.

## 📌 Tiêu chuẩn tuyển chọn

1. Tối thiểu 3 năm kinh nghiệm trong mảng Software Testing, trong đó có ít nhất 2 năm chuyên sâu về Automation Testing.
2. Viết code thành thạo bằng một trong các ngôn ngữ: TypeScript/JavaScript hoặc Java/Python.
3. Có kinh nghiệm vững chắc với các công cụ kiểm thử: Playwright, Cypress, Selenium hoặc Appium.
4. Hiểu biết sâu về RESTful API, HTTP Status Codes, JSON/XML payloads.
5. Hiểu biết về Performance Testing (JMeter/k6) và Security Testing cơ bản là điểm cộng lớn.
6. Kỹ năng giao tiếp, truyền đạt vấn đề mạch lạc; tư duy phản biện sắc bén.
